SYSTEM AUDIO METADATA VISUALIZER · v2
Capture system audio (e.g. a browser tab playing music) and watch the tunnel react in real time. The neon boundary is a scrolling waveform of the music's history. Tiles flash on bass hits, cyan strips pulse, lava-lamp colors shift with chroma. Audio stays local — only metadata drives the visuals.

For tab capture: click START, choose a tab playing audio, tick "Share tab audio". If getDisplayMedia is blocked (common in iframes), use LOAD AUDIO FILE instead.
