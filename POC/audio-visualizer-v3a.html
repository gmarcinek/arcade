SYSTEM AUDIO MESH VISUALIZER · v3
Capture system audio (e.g. a browser tab playing music) and watch the tunnel react in real time. The neon boundary is a scrolling waveform of the music's history. Bass widens the tunnel, lava light blooms on low-end pressure, mid tones deform the mesh, and a jumping yellow tracer ball leaves a rhythm-modulated ribbon. Audio stays local — only metadata drives the visuals.

For tab capture: click START, choose a tab playing audio, tick "Share tab audio". If getDisplayMedia is blocked (common in iframes), use LOAD AUDIO FILE instead.

Keys in-session: S settings · Esc stop · drag & drop audio anywhere
