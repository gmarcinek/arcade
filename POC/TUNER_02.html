Tune / drone / pulse composer

Arrangement map

Pattern: x = hit, X = accent, - = pauza, cyfry 0–9 = nuty skali minorowej jako pitch-offset. Mode drone trzyma dźwięk przez długość loopa. Mode pulse odpala sample rytmicznie. Mode tune traktuje cyfry jako melodię.
