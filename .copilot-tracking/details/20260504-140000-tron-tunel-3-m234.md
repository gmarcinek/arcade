### M2-3 — `src/procedural/trackChunkManager.js` (new)

- Scope: manages a sliding window of `SurfaceSegment` objects, exposes a `trackWorld`-compatible API
- Pattern: factory function (no class), follows `createTrackWorld` style

**Key internal state:**

```js
{
  globalSeed,           // base seed
  nextChunkIndex: 0,    // increments each time a new chunk is generated
  chunks: [],           // ordered array of chunk descriptors
  // chunk descriptor: { id, segment, startGlobalS, endGlobalS, lastPoint, lastNormal }
}
```

**Chunk generation algorithm (single chunk):**

1. `rng = seededRng(globalSeed + chunkIndex)`
2. `segLen = lerp(SEGMENT_LENGTH_MIN, SEGMENT_LENGTH_MAX, rng())`
3. Start point = `lastChunk.lastPoint` (or `Vector3(0,0,0)` for chunk 0)
4. Start tangent = `lastChunk.lastTangent` (or `Vector3(0,0,1)`)
5. Build `N` intermediate control points by walking from start point in start tangent direction, then bending progressively. Each step:
   - `dxz = (rng()-0.5) * 2 * MAX_TURN_XZ` per point
   - `dy = (rng()-0.5) * 2 * MAX_TURN_Y` per point
   - Points spaced roughly `segLen / (N+1)` apart
6. End point is placed to close the walk; pushed onto `points` array
7. `buildCurve(points, lastChunk.lastNormal)` → `curveData`
8. `makeSurfaceSegment('seg-'+chunkIndex, 'tube-inner', curveData, TUNNEL_R, curveData.length)`
9. Safe track: sinusoidal, `baseU` seeded, amplitude/frequency seeded; **first sample `u` = `lastChunk.lastSafeU`** for u-continuity
10. Store `lastPoint`, `lastNormal`, `lastTangent`, `lastSafeU` from final sample/frame of this chunk

**Exposed API:**

```js
return {
  trackWorld,              // live trackWorld with addSurface/removeSurface wired in
  update(activeSurfaceId, localS),  // generate ahead / discard behind
  getFirstSegmentId(),
  advanceToNextSegment(currentId),  // returns next chunk id or null
  getSegmentLength(id),             // returns segment.length for current segment
};
```

**`update(activeSurfaceId, localS)` logic:**

- Compute player's global position index: `playerChunkIdx = chunkIndexFromId(activeSurfaceId)`
- Generate until `chunks.length - 1 - playerChunkIdx >= LOOKAHEAD_SEGMENTS`
- Remove (and call `trackWorld.removeSurface`) chunks where `chunkIndex < playerChunkIdx - TRAIL_SEGMENTS`

**Segment advance:**

```js
function advanceToNextSegment(chunkManager) {
  const nextId = chunkManager.advanceToNextSegment(state.activeSurfaceId);
  if (!nextId) return; // end of world (shouldn't happen in infinite mode)
  const overflow =
    state.s - chunkManager.getSegmentLength(state.activeSurfaceId);
  state.activeSurfaceId = nextId;
  state.s = Math.max(0, overflow);
  // u carries over unchanged (continuity guaranteed by chunk manager)
}
```

### M3-4 — `src/ball.js` additive

- Scope: new export `updateBallPositionFromFrame(carGroup, frame)`
- Algorithm: set position from `frame.position`; build orientation matrix from `frame.forward`, `frame.normal` (which is inward = "up" for the ball), `frame.binormal`

```js
export function updateBallPositionFromFrame(carGroup, frame) {
  carGroup.position.copy(frame.position);
  // Orientation: forward = frame.tangent, up = frame.normal (inward)
  const m = new THREE.Matrix4().makeBasis(
    frame.binormal, // right
    frame.normal, // up (inward normal)
    frame.tangent, // forward
  );
  carGroup.quaternion.setFromRotationMatrix(m);
}
```

- Main check: ball sits flush on tube wall, aligned with travel direction.

## Risks

- **RMF normal pop at boundaries**: if `lastNormal` is stored before normalization, or if the projected `initialNormal` is near-zero, the next chunk will flip. Store the normalized last RMF normal explicitly after each chunk is generated.
- **u-continuity at safe track boundaries**: the chunk manager must read `lastSafeU` from the last sample of the previous chunk's safe track and seed the new chunk's `baseU` from it. Forgetting this causes a hard angular jump in the safe track at the boundary.
- **`update()` called with stale id**: if `state.activeSurfaceId` is never initialized (null), `chunkManager.update` will miscompute the player chunk index. Ensure `startGame()` always sets `activeSurfaceId` before game starts.
